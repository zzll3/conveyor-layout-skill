# 输送线布局识图 Skill

Cursor / Grok Bot 用的输送线 AutoCAD 布局识图技能。

## 当前版本

**V1.10（2026-10-19）**

规则来源锁定（勿混用中间版）：

| 规则块 | 口径 | 要点 |
|--------|------|------|
| **正反向判端** | **V1.0** | 单头青/浅蓝块状大箭头 → 箭向=正向；双头或无箭 → 才用远侧到位 |
| **任务传递** | **V1.8** | 青大箭（单头仅箭向 / 双头双向）+ 接收侧到位门禁；表只记「任务传出」 |

其它：移栽=`ss+yz+sj`；黄细箭不作传递、不定正反；**识图全程不得参考程序**。

## 安装

将 `输送线布局识图/` 复制到 agent 的 workflows（或 skills）目录。
