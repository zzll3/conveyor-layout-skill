# 输送线布局识图 Skill

Cursor / Grok Bot 用的输送线 AutoCAD 布局识图技能。

## 当前版本

**V1.7（2026-10-19）**

- 移栽机构：`ss+yz+sj`（都带 sj；表内 `FB2_sj` 打勾）
- 任务传递：青/浅蓝块状大箭头（单头=仅箭向；双头=双向）+ 接收侧对应运行方向到位门禁
- 表只记本机「任务传出」，不写「任务传入」
- 黄细箭不作传递；正反端另看到位光电；禁程序旁证

## 安装

将 `输送线布局识图/` 目录复制到 agent 的 workflows（或 skills）目录即可。
