## 0. 证据边界（硬规则）

### 不得参考程序

识图（判类型 / 高低 / 正反 / 对接 / 任务传出 / IO 归属 / 运行逻辑）**全程不得参考程序**，包括但不限于：

- 博图 / TIA Portal / Openness / 任意 FC·FB·DB·OB
- 「前机 / 后机 / 任务传递块 / 使能段 / 路径方向」等程序段或注释
- 以程序结果反推图面，或用程序旁证改写图面结论

图面与程序冲突时：**以图面为准**；差异可另列「与程序差异」备注，但**不得**用程序改判图面。  
用户若单独要求「对程序 / 改 FC」，那是**另一项任务**，不得并入本 Skill 的识图证据链。

| 允许（仅图面） | **禁止** |
|----------------|----------|
| 外形、**青/浅蓝块状大箭头**（含双头）、到位光电文字与端位、楼层、邻机几何、图面导出 IO | **任何程序**；**黄细箭**定传递或定正反 |

## 1. 读图顺序

上层/下层 → 类型外形 → **§3 正反端（V1.0）** → **§4 任务（V1.8）** → 填表 → IO/逻辑。  
全程只读 CAD，**不打开、不对照程序**。

---

## 2. 类型 / 高低 / 型

输送 `ss`；移栽 **`ss+yz+sj`**（本项目移栽均带 sj；与纯升降区分）；升降 `ss+sj`（须上下层对照，无 yz）。  
升起=高位 `yz`；降下=低位 `ss`。型①高上下/低左右；型②高左右/低上下。每台自判。对接只填直接邻机。

---

## 3. 正反向判端（口径 = V1.0）

**优先级：**

1. **先看本台该轴上的青/浅蓝块状大箭头**
   - **单头**：箭指向 = 该轴 **正向**；箭尾侧 = 反向
   - **双头** 或 **无青大箭**：不能用青箭定正反，改走第 2 步
2. **否则**用远侧到位：远侧到位 = 本节→下一节直接运行方向；复合光电只取「到位」
3. 黄细箭 **不得**定正反端
4. **不得**用程序信号名、前机后机、FC 注释定正反

> 说明：V1.6–V1.7 曾写成「青箭不定正反、只看远侧到位」——**已废止**；正反一律按本节约 V1.0。

---

## 4. 任务传递（口径 = V1.8）

| 青箭 | 传递 |
|------|------|
| 单头 | 仅箭向 |
| 双头 | 该轴双向 |

A→B 有青箭后：接收侧 B 须有对应运行方向到位（顺 B 正向进 → 正向到位；逆 → 反向到位）；缺则无路径。  
正向本身按 §3（V1.0）已判定（可与单头青箭同向）。

**本机只写出站**：仅 **`任务传出`**，`→邻机`，多项 `;`。不建「任务传入」列。  
黄细箭 **不作**任务传递。  
**不得**用 FC 任务块、使能段、旧表程序列补传出。

---

## 5. 交付物

编号总表（含型①/②）+ 对接列 + **任务传出** + IO + 逻辑/待核。  
可选：图面与程序差异清单（仅标注，不改判图面）。

## 6. 质量门（踩雷即错）

- **参考程序**定正反 / 对接 / 任务 / 类型 / 高低
- 黄细箭定传递或正反
- 双头青箭仍当单向定正向
- 有单头青箭却改用远侧到位抢判正反
- 单头当双向传递
- 有青箭无接收侧到位仍写路径
- 本机行写「任务传入」列
- 移栽漏 sj（写成仅 ss+yz）
