## 1. 读图顺序

上层/下层 → 编号外形与类型 → **§5 正反端（到位光电）** → **§6 任务传递（青大箭 + 到位门禁）** → IO / 逻辑。

## 2. 类型与对接列

| 类型 | 机构 | 注意 |
|------|------|------|
| 输送机 | `ss` | — |
| 移栽 | `ss`+`yz` | 可有 DS；**勿单凭 DS 判升降** |
| 升降 | `ss`+`sj` | 必须上层+下层对照 |

对接列：移栽/升降用 **高/低 × 正/反**；普通用 **正向/反向对接**。只填直接邻机，不跨中间机。

## 3. 移栽高低与型

| 状态 | 运行 | 高度 |
|------|------|------|
| 升起 | `yz` | **高位** |
| 降下 | `ss` | **低位** |

| 型 | 升起后走向 | 高位 | 低位 |
|----|-------------|------|------|
| **①** | 上下 | 上下 | 左右 |
| **②** | 左右 | 左右 | 上下 |

每台自判；禁止套别台、禁止用程序反推高低轴。横/竖只表图面方位。

---

## 4. 正反向判端（§5）

只定对接表里的正/反端。

1. **远侧到位 = 本节→下一节的直接运行方向**（禁止说「本节在下一节反向处」）。
2. 复合光电只取「到位」义（`正向减速/反向到位` → **反向到位**）。
3. 远侧缺失时：某向到位在哪一端，该端即该向到达端。
4. **青大箭不定正反端**（正反端只看到位）。
5. 高位轴优先 `YZ…到位`；低位轴优先 `SS…到位` 或复合到位。

---

## 5. 任务传递（§6 · 核心提炼）

> 能否传递 ≠ 正反端怎么填；两者常同向，但必须各走各的证据。

### 5.1 箭头：只认青大箭

| 图面 | 用途 |
|------|------|
| **青/浅蓝块状大箭头** | 任务传递**唯一**箭头依据 |
| 黄细长示意箭 | **不作**传递依据 |

| 青箭形态 | 传递 |
|----------|------|
| **单头** | **仅箭向**（A→B 有箭 ≠ 允许 B→A） |
| **双头** | 该轴**双向**可传 |

本机出站 ← 本机青箭指向邻机；谁→本机 ← 邻机青箭指向本机。分轴：箭在哪根轴只约束该轴；移栽高低轴分开。

### 5.2 门禁：接收侧「对应运行方向」到位

青箭（含双头之一向）给出 A→B 之后，还须 **B 有对应到位**，否则**删除路径**。

| 料在 B 上的运行 | B 需要 |
|-----------------|--------|
| 朝 B 的**正向**进入/到位 | **正向到位**（或该轴 SS/YZ 正向到位） |
| 朝 B 的**反向**进入/到位 | **反向到位**（或该轴 SS/YZ 反向到位） |

口诀：

- 从 B 的**正向侧邻机**回传进 B → 要 B 的**反向到位**
- 从 B 的**反向侧邻机**顺向进 B → 要 B 的**正向到位**

减速、DS 上/下、边缘 **不能**代替到位。缺到位 → 无路径（即使有青箭）。

**推论（写进交付时用）**：本台某轴**正、反向到位都有**，且邻侧青箭允许，则该轴两侧都可能传入；只有单向青箭的链，逆箭向一律无出站。

### 5.3 交付写法

- **本机传出**：目标 + 青箭（单/双头）+ 接收侧到位
- **他机传入**（可选）：来源 + 邻机青箭 + 本机对应到位（无则「无路径」）
