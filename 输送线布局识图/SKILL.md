# 输送线布局识图

**版本：V1.0（2026-10-19 定稿）**  
规则变更须升版本号（V1.1…）并经用户确认；个案纠错只写进示例或项目笔记，不直接改 V1.0 正文口径。

从 AutoCAD 输送线布局图识别设备类型、流向、对接、光电与 IO，整理编号表、IO 表与运行逻辑。图例多为「输送线点位」；单向大箭头常表示物料正向。

**正文规则只用「本节 / 下一节 / 本台」；具体输送编号仅可出现在「示例」中，不得当成可全局套用的结论表。**

---

## 1. 何时使用

- 打开/导入输送线 DWG/DXF，或已用 CAD-MCP 连图
- 需要类型、方向、对接、移栽/升降高低位、IO、运行逻辑

## 2. CAD 与读图顺序

优先 AutoCAD MCP（常见命名空间 `autocad`）。配置因机器而异；先查工具描述再调用。不可用则用截图 / PDF / 点位导出，并标明证据来源。

读图顺序：**上层/下层 → 图层块 → 编号外形 → 箭头 → 光电 → IO / 程序握手**。

## 3. 输送类型

| 类型 | 机构 | 含义 |
|------|------|------|
| 输送机 | `ss` | 仅滚筒 |
| 移栽输送机 | `ss`+`yz` | 降下滚筒贯通 + 升起移栽；可有 DS 顶升 |
| 升降输送机 | `ss`+`sj` | 上下层同号，高低对接不同 |

- DS 上/下到位 = 移栽顶升，**不要单凭 DS 判成升降**。
- 程序里若编成 `ss`+`sj`（仅 DS）但外形/任务是移栽，**识图仍按移栽**；以图面与任务传递为准，FC 机构名为旁证。
- 升降必须**上层 + 下层对照**才能判走向与高低对接。

对接列：
- 移栽 / 升降：高位正向、高位反向、低位正向、低位反向
- 普通输送：正向对接、反向对接

---

## 4. 移栽高低（核心）

### 4.1 升/降决定高/低（每台自判）

| 状态 | 运行 | 高度 |
|------|------|------|
| **升起来** | **移栽 `yz`** | **高位** |
| **降下去** | **输送 `ss`** | **低位** |

图面：横着=左右，竖着=上下（只表方位，**不定高低**）。

禁止：套别台轴向；用「哪侧普通机更多」定高低；单用 FC 接线反推高低轴。

### 4.2 型① / 型②

| 型 | 升起后移栽走向 | 高位 | 低位 |
|----|----------------|------|------|
| **①** | 上下 | 上下 | 左右 |
| **②** | 左右 | 左右 | 上下 |

低位 = 与高位垂直的降下滚筒轴。按本台外形归类，禁止混套。

辅助：本机「正/反向减速·到位」所在轴多半是滚筒轴=低位；垂直轴=移栽=高位。旁侧邻机箭头 ≠ 本台轴证据。

### 4.3 邻机不得跨过中间机

同一轴上看对接时，只填**几何上直接相邻**的邻机。中间若夹升降/其它机，不得把远端同向机填进本台高/低对接列。

---

## 5. 正反向判端（核心）

### 5.1 远侧到位 = 本节→下一节的直接运行方向

口诀：**远侧到位标签 = 本节向下一节跑的直接方向**。  
禁止口诀：「本节在下一节的反向处」。

步骤：

1. 取对接边 **本节 → 下一节**
2. 在下一节上找沿该边、**远离本节**的一端（远侧）
3. 只读该端光电的**到位**义（见 5.2）
4. 远侧正向到位 → 直接方向=**正向**；远侧反向到位 → =**反向**
5. 填下一节（同轴）：
   - 直接方向正向 → 下一节正向对接=远侧邻机，反向对接=本节
   - 直接方向反向 → 下一节反向对接=远侧邻机，正向对接=本节

禁止：用下一节近侧光电、或只用本节光电，单独定下一节正反端。

**示例（编号非规则）**：A→B，B 远侧为「反向减速/正向到位」→ 取正向到位 → A→B=正向 → B 正向对接=远侧邻机、反向对接=A。

### 5.2 复合光电

| 图面原文 | 判向只用 |
|----------|----------|
| 正向减速 / **反向到位** | **反向到位** |
| 反向减速 / **正向到位** | **正向到位** |

IO 表可保留全文；填对接列只采用到位义。

### 5.3 本台光电端位（远侧缺失时）

某向「到位」在哪一端，该端即该向运行的到达端。须看插入点/引线相对质心与邻机的近远；文字常漂，单侧光电标待核。

### 5.4 程序握手旁证（FB0 类前/后机）

若总控同轴有前机/后机握手：先在**已用远侧到位核清的一台**上确认约定，再旁证其它台。已核常见约定：

- **前机 = 反向侧**
- **后机 = 正向侧**

另可看「输送/移栽正转·反转传递」任务块：正转后机侧≈正向对接，反转后机侧≈反向对接。

信号名含「正向/反向」只表示接到正/反到位输入，**≠**对接列该填谁。ss/yz 交叉接线时，以远侧到位与前/后机为准。

**示例（编号非规则）**：已确认前=反、后=正；某台 yz 后机=北邻、ss 前机=东邻 → 高正=北邻、低反=东邻；即使点名为「YZ反向到位」，也不得仅凭名称写成高反=北邻。

### 5.5 双向箭头

只表该轴可正反跑、对齐轴向；**不定正反端**。

### 5.6 光电选用

高位轴优先 `YZ…到位`；低位轴优先 `SS…到位` 或复合到位。

---

## 6. 普通输送 / 升降

- 普通：正向/反向对接；判端同 §5.1
- 升降：上下层对照；高位≈上层对接，低位≈下层对接

## 7. IO 字段建议

`点位地址`、`信号名称`、`类型`、`关联输送编号`、`关联机构`、`高低位`、`备注`

## 8. 交付物

1. 编号总表（移栽标型①/②）
2. 对接与高低位明细
3. IO 表
4. 运行逻辑 + 待确认项（单侧光电、CAD 不可用、交叉接线、程序机构名与外形不一致等）

## 9. 工作步骤

1. 分层，枚举编号与类型
2. 移栽：升/降定高低 → 型①/② → 直接邻机（不跨中间机）
3. 每条边：远侧到位 → 直接运行方向 → 填正/反对接；有程序则用前/后机与任务传递交叉核
4. 升降上下层对照
5. 用户纠正：抽象成规则后**升版本**写回；个案编号只进示例或项目笔记

## 11. 常见错法

| 错法 | 应改 |
|------|------|
| 「远侧正向到位 ⇒ 本节在下一节反向处」 | 远侧到位 = 本节→下一节**直接方向** |
| 用复合名里的「减速」判向 | 只保留「到位」 |
| 信号名有「YZ反向」就填高反 | 看端位或 yz 前/后机 |
| 有「SS正向」在邻侧就填低正 | 先远侧规则或 ss 前/后机 |
| 双向箭头尖端当正向 | 箭头只表可双向 |
| 左右=低、上下=高打天下 | 每台升/降 + 型①/② |
| 隔着升降机对接远端移栽 | 只填直接邻机 |
| 程序写 ss+sj 就判成升降 | 有 DS 移栽外形仍判移栽 |
