# 输送线布局识图

从 AutoCAD 输送线布局图中识别设备类型、流向、对接关系、光电与 IO，并整理成编号表、IO 表与完整运行逻辑。图例是**输送线点位**；图上大箭头表示物料流转方向。

## 何时使用

- 打开或导入输送线布局 DWG/DXF，或用户已通过 CAD-MCP 连上图纸
- 需要按箭头、编号、光电位置、IO 点位理解整线流程
- 需要输出：输送清单、对接关系、移栽/升降高低位逻辑、IO 表、运行逻辑说明

## CAD 连接（CAD-MCP）

优先用已配置的 AutoCAD MCP（命名空间常见为 `autocad`）读图上的实体、图层、块、文字、标注。典型本地启动配置（路径按现场调整）：

```json
"autocad": {
  "command": "D:\\soft\\mcp-servers\\CAD-MCP\\.venv\\Scripts\\python.exe",
  "args": ["D:\\soft\\mcp-servers\\CAD-MCP\\src\\server.py"]
}
```

使用前：确认 AutoCAD 已打开目标布局图；先 `GetDynamicTools` 查看该 MCP 实际工具名与参数，再调用。若 MCP 不可用，则根据用户导出的截图、PDF、DXF 文本、图层说明或粘贴的点位表继续分析，并标明证据来源（图上可见 / 推断 / 待确认）。

读图顺序：
1. 找到「上层 / 下层」分区（或等效标注），升降机必须上下层对照读
2. 图层与块定义（输送、移栽、升降、光电、IO、箭头、编号文字）
3. 输送编号与设备外形/块属性
4. 大箭头（主流向，常为双箭头）与局部箭头
5. 光电符号及相对输送的安装位置；用远端光电名判定正反向（见下）
6. IO 点位文字或表格（地址、名称、关联设备）

## 输送类型定义（必须按此分类）

| 类型 | 代号组合 | 含义 |
|------|----------|------|
| 输送机 | `ss`（滚筒） | 仅滚筒输送，单高度输送方向 |
| 移栽输送机 | `ss`（滚筒）+ `yz`（移栽皮带） | 低位走滚筒方向；高位走移栽皮带方向 |
| 升降输送机 | `ss`（滚筒）+ `sj`（升降） | 高位、低位各自对接不同输送 |

识别规则：
- 从图块名、属性、附近文字、图例对照判定类型；无法判定标为「待确认」并列出依据
- 编号统一整理（保留图上原编号；必要时给出规范化别名，但原号优先）
- `ss` / `yz` / `sj` 为机构代号，不要与 IO 地址混淆

## 方向与对接（核心）

### 正向 / 反向判定（必须遵守）

1. **图上箭头方向 = 正向**（常见为双箭头）。箭头指向的一端为正向下游。
2. **下一节输送线远端光电**：若标注为「正向光电 / 正向到位 / 正向边缘」等含「正向」字样，则该节当前判定方向为**正向**；若远端是「反向…」或未标正向，则相对本机为**反向**侧。
3. 本机「反向到位」光电通常在箭头相反的一端，可与箭头互相核对。

### 通用对接

- **连通对接**：两段输送在端口几何相邻、图元连接或文字标明对接时视为连通；记录「本机出口方向 → 下游编号」与「本机入口方向 → 上游编号」
- 移栽、升降的高低位对接以图面几何 + 用户/图例说明为准，禁止只看单侧邻号就断定高低位

### 普通输送机（仅 ss）

记录：
- 输送编号、类型=输送机
- 主输送方向（箭头正向；相对图纸：上/下/左/右）
- 上游对接输送、下游对接输送
- 本机光电列表及作用；用远端光电名核对正反向

### 移栽输送机（ss + yz）

必须分开高低位：

**低位（滚筒 ss）**
- 低位输送方向（箭头正向）
- 低位对接的输送（可一侧或两侧）

**高位（移栽皮带 yz）**
- 高位移栽方向（通常与低位垂直或图示箭头方向）
- 高位对接的输送

另记：移栽升/降、DS 顶升到位、YZ 正向到位等 IO/光电（若图上有）。

示例（广州招行点位图，用户确认）：**1002** 高位对接 **1001**，低位对接 **1003**。

### 升降输送机（ss + sj）

**必须结合上层与下层平面一起看**，才能判断升降走向与高低位对接；同号在上下层各出现一次时，分别读邻机与箭头，再合并为一台升降机的高低位。

**高位（上层）**
- 高位对接的输送（可多台，逐条列出）
- 高位时滚筒输送方向（箭头正向）

**低位（下层）**
- 低位对接的输送
- 低位时滚筒输送方向

另记：升降到位（上/下）、极限、滚筒正反向光电。图上「下层450H / 上层950H」一类标注用于区分上下层图区。

## 光电与 IO

- 光电：记录编号/名称、安装在哪台输送的哪一侧（入口/出口/中部/移栽侧）、正反向属性
- IO：整理为表格，字段至少包含：`点位地址`、`信号名称`、`类型(DI/DO/AI/AO)`、`关联输送编号`、`关联机构(ss/yz/sj/光电)`、`高低位(若适用)`、`备注`
- 图上只有中文名无地址时，地址列填「图上未标」，名称照录
- 同一光电若同时出现在布局与 IO 表，合并为一行并交叉引用

## 输出交付物（按此结构给出，缺项标明）

### 1. 输送编号总表

| 编号 | 类型 | 机构 | 主方向/低位方向 | 高位方向(若有) | 上游 | 下游 | 备注 |

### 2. 对接与高低位明细

按每台设备写清：
- 输送机：正向 + 上下游
- 移栽：低位方向/对接；高位移栽方向/对接
- 升降：上层对接；下层对接；升降走向（上↔下）

建议同时给出一张**流向简图**（可用 mermaid `flowchart` 或分层文字）。

### 3. IO 表

完整表格（见上文字段）。可按输送编号分组。

### 4. 完整运行逻辑

用「工况 → 条件 → 动作」描述整线，至少覆盖：
1. 主输送线按箭头正向的正常过件顺序
2. 每台移栽：低位贯通 vs 高位移栽去向、回低位条件
3. 每台升降：上层与谁交换、下层与谁交换、升降互锁
4. 关键光电如何构成到件、放行、堵料、互锁
5. 不确定处单独「待现场确认」列表，禁止静默编造点位地址或未见图的联锁

## 工作步骤（执行清单）

1. 连接或打开图纸；标出上层/下层图区
2. 枚举全部输送编号并判定类型（ss / ss+yz / ss+sj）
3. 依据大箭头（正向）建立主流向；用远端正向光电核对
4. 对每台设备填写方向与对接；移栽/升降强制拆高低位；升降必须上下层对照
5. 挂接光电位置与正反向
6. 整理 IO 表并与设备、光电对齐
7. 写出完整运行逻辑与待确认项
8. 用原图编号做一次回溯核对

## 质量要求

- 结论必须能指回图上的箭头、编号或点位；推断须标注
- 移栽/升降未写清高低位对接，视为未完成
- 升降机只看单层下结论，视为未完成
- 不要把普通输送机当成移栽或升降
- 用户补充图例或点位规则时，以用户最新定义为准并更新本轮输出与本 skill
